## INTRODUCTION
Mission & CE file required for using Green County map.

* dayzOffline.GreenCounty : Must be uploaded on your mpmissions folder (on your server) for an original summer/spring variant.
* ColdWeather.GreenCounty : Must be uploaded on your mpmissions folder (on your server) if you play EarlyWinter/Winter variant.
* GreenCounty_CE : This folder contains all file for Economy editing with the Economy Editor. Don't upload this on your server.

## SEASONAL EVENTS
### DISCLAIMER
The seasonal events have been adapted for Green County 1.1.17. These are not a priority in the map's development and may not always be up to date. They are provided for entertainment purposes only, so you must verify that they function properly and make any necessary adjustments BEFORE deploying them to a public server.

### EVENTS
* WalpurgisNight.GreenCounty (EarlyWinter variant recommanded)
* Christmas.GreenCounty (EarlyWinter or Winter variant recommanded)
* Halloween.GreenCounty (EarlyWinter variant recommanded)

### USAGE
The files include only the changes that need to be made to or added to the base files dayzOffline.GreenCounty and ColdWeather.GreenCounty.
We recommend using a tool such as diff or WinMerge.
